# Benchmarks, Toolkits & Watermarking

---

## 1. MAGE: Machine-Generated Text Detection Benchmark

* **Repository:** [yafuly/MAGE](https://github.com/yafuly/MAGE)
* **Paper:** *MAGE: Machine-generated Text Detection in the Wild* (Li et al., ACL 2024)
* **Scope:**
  * Tests detectors across **57 generator models** (GPT-3.5, GPT-4, LLaMA-1/2, Vicuna, GLM, FLAN-T5, Mistral).
  * Covers **10 task domains** (News, Creative Writing, Q&A, Summaries, Technical, Code).
  * Evaluates both in-distribution and out-of-distribution robustness against evasion attacks (paraphrasing, adversarial perturbations, translation round-trips).
* **When to Use:** Use MAGE scripts when you need to rigorously benchmark and stress-test your detector before deploying to production.

---

## 2. MGTBench: Standardized Evaluation Toolkit

* **Repository:** [xinleihe/MGTBench](https://github.com/xinleihe/MGTBench)
* **Paper:** *MGTBench: Towards a Comprehensive Evaluation of Machine-Generated Text Detectors* (He et al., 2023)
* **Implemented Detection Algorithms:**
  1. **Metric-Based (Statistical):**
     * Log-Likelihood ($\log P(x)$)
     * Rank / Log-Rank
     * Predictive Entropy
     * LRR (Log-Likelihood Log-Rank Ratio)
     * NPR (Normalized Perturbation Ranking)
  2. **Model-Based:**
     * DetectGPT
     * RoBERTa / DeBERTa classifiers
* **When to Use:** Great toolkit for quickly running 10+ algorithms on a custom dataset with standardized accuracy, AUROC, and F1 reports in one command.

---

## 3. Mimir: Membership Inference & Text Auditing

* **Repository:** [iamgroot42/mimir](https://github.com/iamgroot42/mimir)
* **Focus:** Audits whether a text was part of an LLM's pretraining data (Membership Inference Attack - MIA) and detects machine-authored passages under noisy conditions.
* **Included Baselines:** LOSS, Reference-based Likelihood Ratio (Min-K% Prob, Carlini et al.), Zlib entropy, Neighbor-based curvature.

## 4. LM-Watermarking (Statistical Watermarking)

* **Repository:** [jwkirchenbauer/lm-watermarking](https://github.com/jwkirchenbauer/lm-watermarking)
* **Paper:** *A Watermark for Large Language Models* (Kirchenbauer et al., Univ of Maryland, ICML 2023 Best Paper Award)
* **How Watermarking Works:**
  1. **During Generation (Embedding):**
     * The generator computes a hash of the preceding $k$ tokens using a secret key seed.
     * The hash pseudorandomly splits the vocabulary $V$ into a "Green List" $G$ (size $\gamma |V|$) and a "Red List" $R$.
     * A bias $\delta > 0$ is added to the logits of tokens in the Green List:
       $$\ell'_i = \ell_i + \delta \cdot \mathbb{I}(i \in G)$$
     * The model samples from these modified logits, subtly preferring Green tokens without noticeably hurting fluency.
  2. **During Detection (Verification):**
     * The verifier does **not** need the original LLM weights or GPU!
     * Using the same secret key and hash function, it counts how many tokens in the candidate passage belong to the Green List ($|S|_G$).
     * Null hypothesis ($H_0$): Text was written by a human without the watermark rule ($\mathbb{E}[|S|_G] = \gamma T$).
     * Computes the $z$-score:
       $$z = \frac{|S|_G - \gamma T}{\sqrt{T \gamma (1 - \gamma)}}$$
     * If $z > 4.0$, $p$-value $< 3 \times 10^{-5}$, mathematically proving the text was generated by the watermarked LLM with near 100% certainty.
* **When to Use:** Essential for platform operators (AI API providers, internal enterprise AI portals) wanting provable attribution without false positives.
